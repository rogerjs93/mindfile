MindFile

An AI-native, self-clustering file format.

Ready
PythonTurso/libSQLembeddings

The .mind format stores content in a Turso/libSQL database that self-organizes into versioned semantic clusters, with content-verified save points and data-integrity as the first priority.

Key features

  • Content self-clusters into semantic groups on save
  • Versioned clusters with a full history
  • Content-hash-verified save points
  • Validation and data integrity prioritized over size
  • Fourteen tests plus an EEG demo
